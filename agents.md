# Personal AI Agents and Assistants

Browse software that acts as a personal assistant, messaging agent, persistent AI teammate or self-hosted bot. Read each profile for editorial status and capability evidence.

### Personal assistants

- [AionUi](https://www.aionui.com/en/) — AionUi is a desktop workspace with a built-in agent and connections to existing coding agents. It can prepare documents, work with local files, coordinate agent teams and schedule tasks. Remote web and messaging access still depend on a running host and correct permissions. [Radar Scout profile](https://my-tierroom.party/agents/aionui).
- [Alfi · Text.ai](https://www.text.ai/) — Plan a dinner, create an event, set reminders or split a bill with friends. The full app includes group chats, restaurant cards, images and games; this is social coordination rather than a computer-control workspace. The full Alfi app is on iOS and Android. Alfi Lite works through iMessage and SMS in the US and Canada, and through WhatsApp and Telegram worldwide according to its FAQ. These are different ways to use it. [Radar Scout profile](https://my-tierroom.party/agents/alfi).
- [AppuBot](https://appubot.com/) — AppuBot runs AI teammates on your computer using supported agent accounts. It advertises computer use, editable memory, scheduled routines and skills learned from demonstrations. macOS is the main build, with Windows and Linux downloads also listed. Telegram is a remote conversation channel, not a native phone app. [Radar Scout profile](https://my-tierroom.party/agents/appubot).
- [Bloks](https://bloks.dev/) — Suggested by the community and reviewed against official sources. Bloks is a local-first desktop workspace for role-based personal agents, shared rooms and configurable engines. It combines per-agent memory, automations, tools and review controls, with an iPhone companion. Published documentation describes these capabilities; no founder hands-on test is recorded. [Radar Scout profile](https://my-tierroom.party/agents/bloks).
- [Boba](https://boba.app/) — Ask for reminders, calendar help, email tasks or shared plans in group chats. Boba describes remembering context and making bookings with approval; transactions were not tested here. The official site links both iMessage and a full web chat. It should not be classified as phone-only. No public source license or supported self-hosted distribution was established. [Radar Scout profile](https://my-tierroom.party/agents/boba).
- [Bots · AraraHQ](https://bots.ararahq.com/) — Bots by AraraHQ is an invitation-only service for delegating business tasks to named bots. You work through chats and channels, while bots use a browser in a cloud workspace. It is early: scheduled routines, bot email and the Chief of Staff’s WhatsApp are still listed as coming soon. [Radar Scout profile](https://my-tierroom.party/agents/ararahq-bots).
- [Brea](https://brea.ai/) — Brea is an iMessage-first personal assistant for email, calendar, reminders and browser tasks. The owner sees it as more of the same. iMessage is the verified conversation channel; its privacy policy also mentions an iOS app and other channels whose current availability was not established. [Radar Scout profile](https://my-tierroom.party/agents/brea).
- [Caddy](https://caddy.app/) — Caddy is a phone-oriented assistant in Messages, in the same vein as Instinct. Use iMessage on iPhone or RCS on Android for reminders, connected apps and group plans. No separate app is required; the official site identifies it as a public beta. [Radar Scout profile](https://my-tierroom.party/agents/caddy).
- [Claude Duet](https://claude.com/product/claude-duet) — Anthropic’s personal agent, built around Claude Opus 5.5. It brings over your Claude memory, skills and connected apps into one ongoing thread, sends morning briefs, and works on tasks in a cloud virtual machine with its own browser. It asks for approval before sensitive actions. Research preview through a waitlist for US Pro and Max subscribers; iOS, Android and web access. [Radar Scout profile](https://my-tierroom.party/agents/claude-duet).
- [Clawboo](https://www.claw.boo) — Clawboo is a self-hosted studio for teams of bots. Boo Zero splits a request into tasks and delegates to built-in agents or connected engines such as Codex, Claude Code, Hermes and OpenClaw. It can cover research and marketing as well as code. A team of bots is not the same as separate human accounts. [Radar Scout profile](https://my-tierroom.party/agents/clawboo).
- [Codync](https://www.codync.dev) — The open-source Grok Bot alternative: message Claude Code, Codex, Cursor, Gemini and 40+ AI agents as bots on your own computer, from iPhone, Mac, Windows, Linux or terminal. Free. Also a Muse and Dots alternative. Built in Rust. [Radar Scout profile](https://my-tierroom.party/agents/codync).
- [CraftBot](https://craftbot.live/) — CraftBot offers memory, skills, MCP and tools for everyday work. Its MIT runtime can be self-hosted; CraftBot Live hosts it for you with free and paid plans. My take: more of the same, without a convincing difference from the alternatives. [Radar Scout profile](https://my-tierroom.party/agents/craftbot).
- [Crew](https://crew.you/) — Crew brings email, calendar, files and recurring tasks into web chat and connected messengers. It also offers team accounts and Autopilot missions. This is the hosted assistant at crew.you, a different product from the CrewAI developer framework. [Radar Scout profile](https://my-tierroom.party/agents/crew).
- [Cue](https://cue.im/) — Cue by Manus offers personal agents with phone, email, wallet and computer capabilities, group chats, connected tools and routines. Access requires an invitation code. Store descriptions say Plus is included after access; the App Store also lists paid plans and add-ons. [Radar Scout profile](https://my-tierroom.party/agents/cue).
- [DeepSeek Bot](https://github.com/Fei2411/DeepSeek-Bot) — A team of long-lived bots for DeepSeek Harness, with main bots, bot-to-bot messages and group chats. [Radar Scout profile](https://my-tierroom.party/agents/deepseek-bot).
- [Folk](https://www.folk.com/) — Folk by Nozomio is a hosted personal AI with memory, a cloud computer and proactive routines, reached as a contact through iMessage, Telegram or WhatsApp; no app download is needed. [Radar Scout profile](https://my-tierroom.party/agents/folk).
- [FrockBot](https://frockbot.com) — Persistent AI bots for recurring personal tasks, connected apps and a shared cloud computer. Hosted beta access is available through the browser and macOS app. The code is MIT licensed; the site marks its one-click Cloudflare deployment as coming soon. Manual self-hosting was not validated in this review. [Radar Scout profile](https://my-tierroom.party/agents/frockbot).
- [FullDots](https://github.com/asasemahmed/FullDots) — FullDots is a local-first, self-hosted AI coworker app. Create specialist Dots that use their own browser, files and shell, delegate work, keep editable notes, and run scheduled or webhook-triggered tasks. It is designed for one owner, not a shared human team, and the README labels it alpha. [Radar Scout profile](https://my-tierroom.party/agents/fulldots).
- [Gawkbot](https://gawk.bot) — Gawkbot coordinates bots and existing agent CLIs in a desktop workspace, with a question inbox, memory and small workflow apps. My view: it may be good, but setup is tedious and confusing, and the UI and UX are very poor. [Radar Scout profile](https://my-tierroom.party/agents/gawkbot).
- [Gemini Spark](https://gemini.google/overview/agent/spark/) — Google now calls Gemini Spark “Task” inside Gemini. It handles connected-app workflows, reusable skills, schedules and browser tasks. There is no separate Spark app: access is through Gemini on mobile, Mac or the web. It remains a beta-style experience in the editor’s view; official documentation describes its beta testing and current access requirements. [Radar Scout profile](https://my-tierroom.party/agents/gemini-spark).
- [Grok Bot](https://x.ai/bot) — Persistent bots on cloud computers, with a browser, terminal, collaboration and ongoing context. [Radar Scout profile](https://my-tierroom.party/agents/grok-bot).
- [Guaca](https://guaca.bot/) — Guaca is an open-source macOS workspace inspired by Grok Bot and Muse. Organize agents in crews, with shared conversations, memory and MCP tools. Run the backend locally in Docker or on your own VPS. Its coding workflows support Claude Code, Codex and pi. This review is based on official source and documentation; no hands-on test. [Radar Scout profile](https://my-tierroom.party/agents/guaca).
- [Guilds](https://www.guilds.run/) — Self-hosted guilds combine role-based agents, shared chat, versioned notes and tables, per-agent memory and recurring routines. Inspect prompts, tool results and memory changes after a run. Recipes can be exported and imported; the public recipe directory is still planned. [Radar Scout profile](https://my-tierroom.party/agents/guilds).
- [Happy](https://happy.engineering/) — Open-source coding harness and companion apps for Claude Code, Codex and Grok. Happy connects desktop, iOS, Android and web sessions; it is a developer workflow tool rather than a turnkey personal assistant. [Radar Scout profile](https://my-tierroom.party/agents/happy).
- [Hark Pro](https://hark.com/) — Hark Pro is Hark Labs’ personal assistant for iOS, Android and web. Panels are prompt-generated mini-apps, while Handoff handles web tasks on a cloud computer. Projects organize topical threads rather than independent bots. Specialties and scheduled tasks support recurring work. [Radar Scout profile](https://my-tierroom.party/agents/hark).
- [Hermes Agent](https://hermes-agent.nousresearch.com) — The agent that grows with you [Radar Scout profile](https://my-tierroom.party/agents/hermes-agent).
- [HireAlpha](https://hirealpha.chat/) — Text a Friend, Coworker or Cofounder in iMessage. The site describes briefings, reminders, meeting preparation and follow-ups using the Google accounts you connect. The verified conversation channel is iMessage, which can also work on a Mac. Each of the three personas has a separate number and memory. Entry is currently through a waitlist. [Radar Scout profile](https://my-tierroom.party/agents/hirealpha).
- [Hivekeep](https://hivekeep.app) — Hivekeep is a self-hosted platform of autonomous, persistent personal AI agents. Your AI team. At home. [Radar Scout profile](https://my-tierroom.party/agents/hivekeep).
- [Instinct](https://instinct.com/) — Text or call Instinct and ask it to handle errands in your connected accounts. The appeal is less setup. The trade-off is giving a hosted service access to personal information and permission to act for you. [Radar Scout profile](https://my-tierroom.party/agents/instinct).
- [Iris](https://iris-agent.co/personal-assistant) — Iris is a hosted personal assistant based on Nous Research’s Hermes Agent, accessible through iMessage. It combines persistent context, reusable skills and connected services without requiring the user to run the agent infrastructure. The official page’s metadata explicitly references Hermes; this review does not audit the service’s implementation. [Radar Scout profile](https://my-tierroom.party/agents/iris).
- [KepCup](https://kepcup.app/) — KepCup is an open-source desktop assistant for creating several bots with their own roles, memory and tools. It uses Pi internally and documents MCP, skills, browser tasks and optional external agents. The owner has not tried it yet, but finds the idea promising. [Radar Scout profile](https://my-tierroom.party/agents/kepcup).
- [Kuvo Code](https://www.kuvo.run/code/) — Kuvo Code is primarily a Mac coding workspace, but its persistent bots can also help with research, connected mail/calendar and scheduled tasks. It uses existing agent engines and your own model accounts. Downloads are temporarily unavailable; we could not inspect the linked source repository or test it. [Radar Scout profile](https://my-tierroom.party/agents/kuvo-code).
- [Kwant](https://kwant.si/) — Kwant is a self-hosted personal-agent workspace with bot teams, leaders, shared channels, per-bot memory, skills, MCP and scheduled work. Use Claude, Codex, Grok or your own model endpoints. Guilherme particularly liked the automatic delegation and channels. [Radar Scout profile](https://my-tierroom.party/agents/kwant).
- [Kyku](https://kyku.app/) — Kyku is an iPhone personal assistant in a private TestFlight beta. It advertises help with email, calendars, research, reminders, bookings and purchases using a cloud browser. Access and real-world reliability have not been tested. [Radar Scout profile](https://my-tierroom.party/agents/kyku).
- [LightVela](https://lightvela.ai/) — LightVela hosts Hermes Agent for you, with a visual console and web chat. Choose models, manage bot profiles, and connect messaging channels. The underlying Hermes runtime is open source; the managed LightVela service is a separate paid product. Workbench website publishing and the optional DeepSeek Harness are beta features. [Radar Scout profile](https://my-tierroom.party/agents/lightvela).
- [littleguys](https://www.littleguys.dev/) — A free, MIT-licensed macOS control app by Herval Freire for OpenClaw, Hermes, Claude Code, Codex and other ACP agents. It brings live status, chats, command approvals and scheduled routines into one interface across local and remote machines. The reviewed v0.1.1 release provides a signed installer. Its browser panel uses an OpenClaw gateway; memory and task execution come from the connected runtimes rather than a standalone littleguys agent. [Radar Scout profile](https://my-tierroom.party/agents/littleguys).
- [LobeHub](https://lobehub.com/) — LobeHub brings several models and agents into one workspace. It combines knowledge, editable personal memory, agent groups and scheduled work. You can use its cloud service or run your own deployment; that does not make every integration local or every feature free. [Radar Scout profile](https://my-tierroom.party/agents/lobehub).
- [Lorca](https://lorca.app/) — Desktop runners execute named bots, commands and tools. Phone apps connect to paired runners rather than running the agents themselves. Group conversations coordinate bots sequentially; per-bot Markdown memory and cross-chat recall retain context. [Radar Scout profile](https://my-tierroom.party/agents/lorca).
- [Luke](https://www.getluke.app/) — Luke is a Mac research preview with push-to-talk interaction, personal memory, reusable skills and configurable models. Its product material describes work that continues with user approval. [Radar Scout profile](https://my-tierroom.party/agents/luke).
- [Maestri](https://themaestri.app/) — Maestri is primarily an ADE: a workspace for coordinating coding agents. It is not a ready-made personal assistant in the Grok Bot style. Roles, shared notes, agent handoffs, portals and scheduled routines can be configured for personal-assistant workflows. The underlying agent and model come from the CLI harnesses you install and run; the result depends on their tools and your setup. [Radar Scout profile](https://my-tierroom.party/agents/maestri).
- [Martin](https://www.trymartin.com/) — Martin is a personal assistant with an iPhone/iPad app and web access. Speak or message it to manage calendars, draft emails, organize tasks and notes, and set reminders. SMS, WhatsApp, phone, email and Slack channels are documented. Proactive briefings and inbox workflows depend on the subscription. Included with an iOS focus, not as an Apple-exclusive or fully local agent. [Radar Scout profile](https://my-tierroom.party/agents/martin).

You can talk to the same agent from a terminal, web dashboard or messaging apps. Optional plugins add WhatsApp voice calls and desktop control. Setup, model costs and permissions need attention; we have not tested it. [Radar Scout profile](https://my-tierroom.party/agents/mercury-agent).
- [Migoo](https://migoo.ai/) — The public demo shows specialist agents for research, writing, design, slides and data, with skills, connections and automations. Those announcements must not be counted as released native apps or a working iMessage channel. [Radar Scout profile](https://my-tierroom.party/agents/migoo).
- [Munder Difflin](https://munderdiffl.in) — an open-source alternative to the dots, bots and muses of the world, run an office of claude code/codex like agents on your laptop, sandboxes or anywhere, uses your existing subscriptions [Radar Scout profile](https://my-tierroom.party/agents/munder-difflin).

[Radar Scout profile](https://my-tierroom.party/agents/nordus).

Turn voice notes and messages into notes, tasks, follow-ups and work in connected apps. Its optional Mac/Windows desktop app adds a shared inbox and computer tools. Memory, skills, MCP and agent routing are documented; features and usage limits depend on the plan. [Radar Scout profile](https://my-tierroom.party/agents/notis).

[Radar Scout profile](https://my-tierroom.party/agents/omnibots).

[Radar Scout profile](https://my-tierroom.party/agents/open-dots-anil).
- [OpenAI Dots](https://chatgpt.com/features/dots/) — An always-on ChatGPT agent with its own computer and browser, memory and access to authorized plugins. [Radar Scout profile](https://my-tierroom.party/agents/openai-dots).

Each agent has its own instructions, conversation, files and task queue, with handoffs, shared channels, reusable skills, scheduled routines and a built-in browser. It supports Codex, Claude, Gemini, Grok, OpenCode, Cursor and Cline, plus compatible endpoints and local models. Desktop clients run on macOS, Windows and Linux. The iPhone TestFlight beta and Android app connect to a computer or server running OpenBot. Individuals can run it locally; teams can share a self-hosted or managed server. The public mock illustrates the interface, not independently verified task execution. [Radar Scout profile](https://my-tierroom.party/agents/openbot-nightly).
