# Awesome AI Radar List

A curated, categorized directory of AI agents, developer tools, software and SaaS products. Each entry links to the product and, when it is in the catalog, to its profile on [Radar Scout](https://my-tierroom.party/).

This is an independent selection by Guilherme Vasques. A listing is not an endorsement: check the Radar Scout profile for editorial notes, maturity, licensing and source links. Unknown details stay marked as unknown.

## How the directory works

- Products are grouped by what they do; a product can appear in more than one category when it serves multiple needs.
- “Open source”, “source available” and “closed source” are distinct. See the linked profile for license evidence.
- The Radar Scout profile is the canonical place for current notes, sources, capability details and editorial context.
- Categories are curated, not an automated import. A suggestion does not guarantee publication.

## Submit a suggestion

Open an issue with the product name, official website, repository (if any), and a short explanation of the problem it solves. Suggestions are reviewed before inclusion.
