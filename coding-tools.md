# Agentic Development Environments, Harnesses and Coding Tools

A workspace (ADE) organizes projects and agent sessions; a harness provides the agent runtime and its tools. Some products combine both. Check each Radar Scout profile for source, license and feature evidence.

## Agentic development environments (ADEs)

- [Agent Orchestrator](https://orchestrator.inc/) — Supervision for coding agents, from isolated tasks to reviews and pull requests. [Radar Scout](https://my-tierroom.party/coding?tool=agent-orchestrator).
- [Agent Teams AI](https://agentteams.live/) — Run coding agents as a team around a shared task board. A lead delegates, teammates message each other, and you inspect changes and terminal logs. Supports several existing engines and optional worktrees per teammate. The app is free; providers can charge. Remote SSH execution is still listed as an idea. [Radar Scout](https://my-tierroom.party/coding?tool=agent-teams-ai).
- [Agentastic](https://agentastic.dev/) — A multi-agent development workspace with isolated work and an iPhone companion. [Radar Scout](https://my-tierroom.party/coding?tool=agentastic).
- [Antigravity IDE](https://antigravity.google/product/antigravity-ide) — Google’s agentic IDE for supervised work across editor, terminal and browser, with artifact-based review. [Radar Scout](https://my-tierroom.party/coding?tool=antigravity-ide).
- [bb](https://getbb.app/) — An extensible agent workspace with plugins, orchestration and scheduled work. [Radar Scout](https://my-tierroom.party/coding?tool=bb).
- [Bentomux](https://bentomux.takora.dev/) — A beta desktop workspace for coding-agent terminals on macOS, Windows and Linux. Keeps sessions and agent status together, with approval controls and an optional phone-browser monitor. [Radar Scout](https://my-tierroom.party/coding?tool=bentomux).
- [Capy AI](https://capy.ai/) — A managed platform for fleets of coding agents and automated development tasks. [Radar Scout](https://my-tierroom.party/coding?tool=capy).
- [Clor](https://clor.com/) — A web control plane for coding tasks in local and cloud containers. [Radar Scout](https://my-tierroom.party/coding?tool=clor).
- [cmux](https://cmux.com/) — A native macOS terminal workspace built on Ghostty, with vertical tabs, agent notifications, a browser and SSH workspaces. Free local use; cloud machines and the iOS companion have paid-plan conditions. [Radar Scout](https://my-tierroom.party/coding?tool=cmux).

- [Herdr](https://herdr.dev/) — A terminal ADE for keeping existing coding agents together across local and SSH machines. Terminals survive client disconnects; after a server restart it restores layout and can resume supported sessions, not the original processes. It manages terminals rather than replacing the agents. Apache-2.0 app; model and server costs are separate. [Radar Scout](https://my-tierroom.party/coding?tool=herdr).
- [Jean](https://jean.build/) — A local or self-hosted workspace for coding agents, worktrees and GitHub delivery. [Radar Scout](https://my-tierroom.party/coding?tool=jean).

- [Kiro CLI](https://kiro.dev/docs/cli/) — AWS’s terminal coding harness with reusable skills, MCP integrations, project context and configurable models. [Radar Scout](https://my-tierroom.party/coding?tool=kiro-cli).
- [Letta Agent / Letta Code](https://www.letta.com/agent/) — A memory-first agent harness with its own tools, skills, MCP and model connections. ## Multi-harness workspaces

- [Agentlas Desktop](https://agentlas.cloud/desktop) — A visual control room for specialist agents, goals, files and long projects. It connects existing coding engines and its own Agentlas OS tools. Broader than a code editor: it also handles research and office work. Phone access needs the paired computer; model usage and hosted services have separate terms. [Radar Scout](https://my-tierroom.party/coding?tool=agentlas).
- [Alan](https://tryalan.ai/) — A software delivery control plane that coordinates existing coding agents, shared engineering context, isolated sessions, CI, QA, review and release workflows. Alan orchestrates the agents; the agents perform the coding loop. [Radar Scout](https://my-tierroom.party/coding?tool=alan).
- [CodexHost](https://github.com/BytePioneer-AI/codex-host) — CodexHost brings multiple coding harnesses into Codex Desktop, with separate sessions, parallel delegation, diff review and optional remote hosts over SSH. It complements Codex as a meta-harness; it is not a standalone coding agent. [Radar Scout](https://my-tierroom.party/coding?tool=codexhost).
- [Happier](https://happier.dev/) — Control coding agents from your phone, desktop or browser while they run on your own computer or server. Happier brings Claude Code, Codex, OpenCode and other harnesses into one workspace with parallel sessions, Git review and remote approvals. It is a fork of Happy. Support varies by agent and release channel; delegation, Git writes and scheduled runs include experimental features. [Radar Scout](https://my-tierroom.party/coding?tool=happier).
- [Intentic](https://intentic.dev/) — An open-source workspace by Artur Kurowski for running coding agents side by side in Docker sandboxes. It keeps each task on its own Git worktree, shows changes for review and can delegate between different harnesses. Use your own computer or server, or optional hosted compute. Early project, not tested by us. The native desktop app is Windows/Linux; Mac uses the browser and installer. When using an intentic address, workspace traffic passes through its relay in readable form. [Radar Scout](https://my-tierroom.party/coding?tool=intentic).
- [Omnigent](https://omnigent.ai/) — An orchestration layer over existing harnesses, with shared sessions and policy controls. [Radar Scout](https://my-tierroom.party/coding?tool=omnigent).
- [Solo](https://soloterm.com/) — A programmable workspace where existing coding agents can coordinate terminals and tasks. [Radar Scout](https://my-tierroom.party/coding?tool=solo).
