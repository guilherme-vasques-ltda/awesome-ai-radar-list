# Contributing

Thanks for helping improve this directory.

## Suggesting a product

Open a GitHub issue with:

- Product name and official website
- Repository link, if one exists
- A short, factual description of what problem it solves
- The category or categories where it belongs
- Official sources for claims about features, pricing or license

## Editorial review

Suggestions are reviewed before publication. A suggestion or pull request is not an automatic approval or endorsement. The maintainer may decline products outside the directory's scope, keep details marked unknown, or add caveats when the evidence is limited.

## Keep entries useful

- Prefer official product pages, documentation, repositories and license files.
- Separate released features from announcements, previews and roadmap items.
- Do not claim personal testing unless you actually tested the product.
- Link product entries to both the official product and the corresponding Radar Scout profile when one exists.
- Do not invent origin, funding, price, license, customer claims or security guarantees.
- Keep descriptions short and focused on the problem solved.

## Categories

Use the smallest set of categories that helps a reader find the product. Cross-list a product only when it clearly serves more than one category.
